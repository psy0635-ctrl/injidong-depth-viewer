## 유지하는 제약

- 실제 이가영 서버·Android와의 공동 연결은 미검증. 확정 origin·인증·실제 응답/OpenAPI·적용 한도·시험 ZIP·공동 시각을 확보하지 못했다. 계획을 완료로 승격하거나 접속 실패를 미구현으로 단정하지 않는다.
- 모바일 RGB/Depth 픽셀 정렬·실측 동기화·실제 RGB 컬러 점군은 미검증. 기본 색은 Depth Z 가짜 색이고 ROI는 단색이다. 같은 ID/640×480/가까운 timestamp는 정렬 근거가 아니다. RGB8/RGBA4건 경고를 유지한다.
- 후보 평면은 실제 바닥/중력이 아니며, 사각형 ROI는 주변 바닥을 포함할 수 있는 검토 범위다. 찰흙 정답 마스크·부피 footprint가 아니다.
- 실제 다중시점 정합 정확도·부피/중량 정확도·학습팀 최종 인수는 미검증. 합성부피/탐색정합과 구분한다. 공식 진척률을 산정하지 않는다.
- schema_version="1.0.0", 원본ID·단위·좌표·보정·시각 출처를 유지한다. 원본 촬영/개인ROI/이전ZIP/로그 전체는 신규 게시하지 않는다.

다음 우선 작업은 실서버 인수 자료를 확보한 뒤 기존 PC 클라이언트로 실제 공동 연결을 검증하는 것이다. 최신 코드의 작업 브랜치 게시와 main 병합·팀 승인 완료는 별개다.
